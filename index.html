Georgia Target and Walmart Stores

Target and Walmart are direct competitors that offer similar products and serve overlapping customer groups. This map examines their store locations across the state of Georgia and explores their spatial relationship by identifying the nearest Walmart to each Target store.

Target Stores: The Target store dataset contains store names, location details, and coordinates. This map shows 51 Target store locations in the state of Georgia.

Walmart Stores: The Walmart store dataset contains store names, location details, and coordinates. This map shows 186 Walmart store locations in the state of Georgia.

Data Source: http://www.poi-factory.com/

Red = Georgia Target. Blue = Georgia Walmart. Click a marker for details. Use the controls at the top right to change basemaps or turn store layers on and off.

Analysis

For each Georgia Target store location, the map calculates the straight-line distance to every Walmart and selects the closest one. Distances are measured in kilometers using Leaflet's geographic distance method.
