# GIST 5300 - Midterm Question #8 - Matthew Gaw

Target and Walmart are direct competitors that offer similar products and serve overlapping customer groups. This map examines their store locations across the state of Georgia and explores their spatial relationship by identifying the nearest Walmart to each Target store.

Data Source: http://www.poi-factory.com/

## Map link

https://mgaw2.github.io/Question8_TargetWalmart/ 

## Requirements implemented

- Two datasets: Target store locations and Walmart store locations.
- JSON objects for both datasets created.
- Markers represent store location on map and can be selected by user to reveal more information.
- Distance analysis performed.
- Layer controls allow users to toggle between different tile layers and store layers.
